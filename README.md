# Credit Risk Modeling

## Overview

Проект посвящён построению и сравнению моделей классификации кредитного риска на датасете **German Credit Data**.

В работе рассматриваются два подхода:

- **логистическая регрессия с WOE-преобразованием**;
- **XGBoost**.

## Подход к моделированию

Работа состоит из следующих этапов:

1. Загрузка датасета.
2. Декодирование категориальных признаков.
3. Проведение разведочного анализа данных.
4. Разделение данных на обучающую и тестовую выборки.
5. Расчёт Weight of Evidence (WOE) и Information Value (IV).
6. Отбор признаков с IV > 0.02.
7. WOE-преобразование выбранных признаков.
8. Обучение логистической регрессии на WOE-признаках.
9. Обучение XGBoost на исходных значениях выбранных признаков.
10. Сравнение полученных моделей по ROC-AUC и Gini.

## Результаты

Полученные значения ROC-AUC:

| Model | Train AUC | Test AUC |
|---|---:|---:|
| Logistic Regression + WOE | 0.8235 | 0.7999 |
| XGBoost | 0.9534 | 0.8011 |

Для признака **checking_account** получено значение IV ≈ 0.639, что делает его одним из наиболее информативных признаков в рамках проведённого анализа.
